# An toàn tài khoản và dữ liệu

- Repository hiện **Public**, cấp phép mã nguồn theo **MIT**; vẫn phải kiểm tra `.gitignore` và lịch sử commit để tránh lộ dữ liệu riêng. Giấy phép không bao gồm các luồng IPTV của bên thứ ba.
- Không lưu token GitHub, mật khẩu Apple ID hay dữ liệu ứng dụng IPTV vào mã nguồn.
- Tệp M3U đầu ra, báo cáo và log mặc định không được commit vào repository.
- Script đăng **mã nguồn** không thay đổi Gist IPTV đang sử dụng.
- Chương trình chỉ hỗ trợ quản lý link và kiểm tra dữ liệu; tính hợp pháp/bản quyền của nguồn phát là trách nhiệm của người cung cấp và sử dụng nguồn đó.
- GitHub từng đình chỉ các tài khoản trước; không tự lặp việc tạo repo, không tự đổi tài khoản khi GitHub từ chối. Dừng lại và liên hệ GitHub Support nếu gặp đình chỉ.
- Khi lỗi HTTP hoặc CDN, giữ UNKNOWN thay vì vội xóa kênh đang sống.
- Cần có bản sao lưu `iptv.m3u` tốt gần nhất trước khi bật tự đăng Gist.
